# 易经解读 · 观卦知几

零依赖、可离线的易经解读 Web 应用。纯 HTML + CSS + 原生 JavaScript，**双击 `index.html` 即可使用**，也适合部署到 GitHub Pages。

## 功能

- **起卦占卜** —— 三枚铜钱六次摇卦（掷币动画），自动推演本卦、变卦与动爻
- **六十四卦浏览** —— 按京房八宫分组查阅，支持搜索；每卦含卦辞、彖传、大象传、384 条爻辞与小象传原文及白话解读
- **朱子断法** —— 依《易学启蒙》动爻占法自动选取断辞（无动爻看卦辞、一爻动看动爻、二爻动取上爻……六爻全动用九用六）
- **六爻纳甲装卦** —— 京房八宫定世应、纳甲干支、六亲、六神（按日干）、旬空（按日柱）、月建，日干支含子时换日规则
- **用神断语** —— 依所问之事关键词自动选用神（问财取妻财、问事业取官鬼……），按月建日辰生克与旬空判旺衰、生成断语
- **占例记录** —— 每次起卦自动存入本地（localStorage），可回看、删除

## 快速开始

```bash
# 方式一：直接双击 index.html（浏览器本地打开即可用）

# 方式二：本地服务器（推荐，地址栏更干净）
python3 -m http.server 8931
# 打开 http://localhost:8931
```

## 数据校验与测试

```bash
node scripts/validate.js    # 数据校验：64卦/384爻完整性 + GitHub 开源数据交叉比对 + 八宫推演
node scripts/test-engine.js # 引擎单测：干支纪日锚点、装卦（乾卦标准盘）、本变卦推演、断法
```

经文以通行本《周易》（十三经注疏本）为准（公版古籍），并与 GitHub 开源数据集
[jinkerry/yi_64gua](https://github.com/jinkerry/yi_64gua) 交叉校验：64 卦卦象 100% 一致，
爻辞 98% 逐字一致，其余为刻本异体字差异（如 遯/遁、愬/诉、闚/窥）。
白话解读与装卦引擎为本项目撰写。

## 目录结构

```
├── index.html            # 单页入口
├── css/style.css         # 宣纸·水墨·朱砂中国风主题，响应式
├── js/
│   ├── data/
│   │   ├── najia.js        # 八宫、纳甲、六神、五行生克、旬空等基础表
│   │   └── hexagrams-{1..4}.js  # 64卦数据（经文+白话，每文件16卦）
│   ├── core/
│   │   ├── divination.js   # 铜钱起卦、本变卦推演、朱子断法取辞
│   │   ├── najia-engine.js # 装卦引擎、干支纪日（锚定1949-10-01甲子日）
│   │   └── interpret.js    # 用神选取与旺衰断语
│   └── app.js              # UI 路由与渲染
├── scripts/              # Node 校验与单测
└── reference/            # 交叉校验用的开源数据快照
```

## 部署到 GitHub Pages

```bash
gh repo create yijing --public --source=. --push   # 需已安装并登录 gh
```

然后在仓库 **Settings → Pages** 选择 `main` 分支 `/ (root)`，保存后即可通过
`https://<用户名>.github.io/yijing/` 访问。
